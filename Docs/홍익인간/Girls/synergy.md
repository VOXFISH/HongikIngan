# 전체 시너지 효과 목록

모든 마법소녀가 공유하는 시너지 효과를 이 문서에 모아 작성한다. 현재 목록은 비어 있으며, 기존 기획이나 임시 구현의 항목을 자동으로 채우지 않는다.

마법소녀 문서의 시너지는 아래 목록의 식별자나 이름으로 참조한다. 같은 시너지의 공통 효과를 캐릭터별로 중복 정의하지 않는다. 여러 인원 구간에서 효과가 달라지면 활성 조건과 각 효과를 구분해 적는다. 긴 설명은 표 아래에 제목을 추가해 자유롭게 작성한다.
