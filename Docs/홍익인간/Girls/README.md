# 마법소녀 작성 서식

[Girl%d.md](Girl%25d.md)를 복사해 `Girl1.md`, `Girl2.md`처럼 작성한다. `%d`는 정수 자리이며 제목·파일명·마법소녀 식별자·스킬 및 규칙 식별자를 함께 바꾼다. 캐릭터마다 하나의 Markdown 문서를 사용한다.

상단에는 JSON처럼 보이는 코드 블록으로 기본 정보를 정리하고, 하단에는 캐릭터 설정·스킬 동작·강화 설명·연출·기타 메모를 자유롭게 적는다. 사람이 편하게 작성하고 AI가 전체를 읽어 구현하는 기획 문서다. 한글 필드와 자연어를 사용할 수 있으며, 현재 원본에는 이전 영문 필드도 남아 있다. 엄격한 JSON 문법이나 고정된 형식을 요구하지 않는다. 필요한 항목과 제목을 추가하거나 조정할 수 있고, 모든 설명을 코드 블록 안에 넣을 필요도 없다.

## 함께 작성하는 문서

- [전체 시너지 효과 목록](synergy.md): 모든 시너지의 활성 조건, 효과·수치, 적용 시점을 모아 작성한다.
- [키워드 효과 목록](keywords.md): 모든 키워드의 효과, 적용 시점, 소모·중첩·턴 종료 삭제 여부를 모아 작성한다.

두 목록에는 Girl0–Girl35 구현과 사용자 확인 내용을 반영했으며, 아직 구현되지 않은 기획은 별도로 표시한다. 마법소녀 문서에서는 목록의 식별자나 이름을 참조하고, 공통 효과의 자세한 정의는 해당 목록에 적는다. 캐릭터에만 해당하는 차이나 특수 동작은 캐릭터 문서에서 설명한다.

## 작성 순서

1. 이름·소개·학년·표시 역할군·시너지를 적는다. 역할군은 `지원`, `약화`, `공격` 중 하나다. 독설가의 공통 효과는 약화 역할군을 대상으로 하므로 해당 분류도 정확히 적는다.
2. 스킬을 자연어로 설명하고 발동 계기, 조건, 효과 순서, 대상과 빈 대상 처리를 구체화한다. 조건이 없으면 `없음`, 적용되지 않는 설명은 `해당 없음`이라고 쓴다.
3. 스킬 수치의 초기값과 단위, 강화할 수치 하나, 새 값 계산 방법을 적는다. 예를 들어 `100 + 80 × 강화 후 횟수`는 100 → 180 → 260이며 매번 결과로 교체한다. 이 수치는 설명용이다.
4. 사용하는 시너지와 키워드를 공통 목록에 정의하고 캐릭터 문서에서 참조한다. 참조할 항목이 없으면 빈칸이나 빈 목록으로 둔다.
5. 기본 행동·강화·조건 불충족 사례를 실제 기대값까지 적는다. 위치 교환이나 반응을 사용하면 재행동·연쇄 사례도 추가한다.
6. 아직 정하지 못한 내용은 빈칸 또는 `미정 사항`에 남긴다. 필요한 내용을 확정한 뒤 `작성 상태`를 `구현 준비 완료`로 바꾼다.

체력·방어력·치명타·속도·캐릭터별 가격은 추가하지 않는다. 가격은 학년별 공통 경제 설정을 사용한다. 역할군은 기본적으로 표시용이며, 독설가처럼 명시된 시너지 조건에서는 참조한다. 같은 소녀의 중복 영입은 허용하지 않으며, 계약 해제 후 재영입하면 강화는 초기화된다. 반응 연쇄에 임의 횟수 제한을 추가하지 않는다. 규칙은 [속성 정의](../Magical%20Girl%20Attributes.md)와 [전투 기획](../Game%20System%20Design.md)을 따른다.

## AI에게 일괄 구현을 요청할 때

`Girls/`에서 `작성 상태`가 `구현 준비 완료`인 마법소녀 문서를 대상으로 구현하도록 요청한다. AI는 상단 코드 블록뿐 아니라 하단의 설정·스킬 설명·메모와 참조한 시너지·키워드 정의까지 함께 읽어야 한다. 공통 목록 자체를 마법소녀 문서로 처리하지 않는다.

먼저 식별자 중복, 참조 누락, 미정 값, 강화 계산과 예시의 모순, 대상 선택·효과 순서를 검사하고 차이를 보고한다. 사용자가 지정한 해석 순서는 **최신 확인 답변 → 제목·파일명 및 하단 자연어**이다. 코드 블록은 기획 근거로 사용하지 않고 확정된 자연어에 맞게 수정한다. 해결되지 않는 충돌이나 미정 값은 질문한다. 빈칸을 임의로 채우거나, 적지 않은 값을 0·거짓·효과 없음으로 단정하지 않는다. 작성된 동작 예시를 구현 검증에 사용한다.

문서의 한글 필드명은 코드의 변수명을 강제하지 않는다. AI는 기존 코드 구조에 맞춰 연결한다. 표시 역할군 `지원`·`약화`·`공격`은 현재 구현의 `Buff`·`Debuff`·`Dealer`에 각각 대응한다. 현재 카탈로그와 행동 처리기는 Girl0–Girl35의 복수 효과·강화·이동 연쇄를 지원한다. 새 캐릭터의 동작도 자동으로 지원된다고 가정하지 말고 필요한 확장과 공용 코드에 미치는 영향을 정리한다. 마법소녀 식별자는 영구 식별자로 사용하고 목록 순서로 다시 생성하지 않는다.

실제 콘텐츠는 사용자가 작성한 후 구현한다. 서식의 공란이나 예시는 새 마법소녀·시너지·키워드를 추가하라는 지시가 아니다.
