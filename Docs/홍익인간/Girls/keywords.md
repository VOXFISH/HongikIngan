# 키워드 효과 목록

2026-11-06 기준, Girl0–Girl17 확장의 gamesystem 구현과 사용자 확인 내용을 반영한 공통 정의다. 마법소녀 문서는 아래 식별자 또는 이름을 참조한다. 부여하는 양·확률·강화는 캐릭터 문서에, 부여된 키워드의 공통 동작은 이 문서에 적는다.

## 공통 규칙

- 별도 지시나 논리적 모순이 없으면 **소모 불가·비휘발성**이다. 중첩 가능 여부는 별도로 정한다. 아직 정하지 않은 효과·수치를 임의로 채우지 않는다.
- 소모 여부와 턴 종료 삭제 여부는 독립적이다. 비휘발성은 턴이 끝나도 유지된다는 뜻이며, 다른 보스나 새 게임으로 자동 이월된다는 뜻은 아니다. 현재 구현은 새 전투에서 보스 키워드를 새로 만들고, 학교 복귀 시 아군 키워드를 지운다.
- 중첩은 같은 식별자 아래에 스택을 추가한다. 각 스택은 부여 당시 수치를 유지하며 임의의 최대 스택 제한은 없다. 중첩 불가 키워드가 이미 있으면 재부여를 무시한다.
- 키워드의 **종류 수**는 스택이 1개 이상인 서로 다른 식별자 수다. 예를 들어 표독 5스택과 검은 클로버 3스택은 2종류다.
- `+N%p`는 적용 당시 현재 합동 데미지의 N%를 더한다. 서로 다른 발동은 순서대로 계산한다. 같은 비소모성 키워드의 여러 스택은 아래에 명시한 대로 수치를 합산한다.

### 표독

가키는 액션 시 보스에게 적용된 **키워드의 종류마다 표독 1스택**, 강화 후에는 종류마다 2스택을 부여한다. 보스에게 키워드가 없으면 부여하지 않는다. 이미 존재하는 표독도 한 종류로 센다. 이번 부여량은 부여 직전 종류 수로 한 번 계산한다.

표독 3스택이면 보정 단계에 들어온 데미지 D를 `D × 1.3`으로 만든다. `D × 1.1 × 1.1 × 1.1`이 아니다. 사용한 스택은 그대로 남아 다음 턴에도 적용된다. 독설가 6단계가 활성화되어 있으면 부여량이 두 배가 되며 스택당 10%는 변하지 않는다.

### 검은 클로버

클로에는 액션마다 기본 40%, 강화 후 55% 확률로 보스에게 검은 클로버 1스택을 부여한다. 독설가 6단계에서는 확률 판정을 한 번 하고, 성공하면 2스택을 부여한다.

보스 보정 단계에서 **1스택 소모 → ×1.2 → 남은 스택이 있으면 재발동**한다. 3스택이면 `D × 1.2 × 1.2 × 1.2 = D × 1.728`이고 최종적으로 0스택이 된다. 한 발동에서 모든 스택을 한꺼번에 소모하는 방식은 아니다. 비휘발성이므로 발동하지 않고 남은 스택을 턴 종료라는 이유만으로 지우지 않는다.

귀염둥이 7단계의 소모 방지는 **아군** 키워드에만 적용한다. 보스에게 부여한 검은 클로버는 계속 소모된다.

## 사진부 키워드와 이동 연쇄

지수의 넌 내 꺼야는 2026-11-06 추가 답변에 따라 비중첩·비소모·비휘발성으로 확정했다. 처음 제안한 소모성 스택 방식은 사용하지 않는다. 강화는 공격이 끝날 때마다 추가 피해 500을 적용한 다음 현재 합동 데미지를 10%p 늘린다. 키워드를 부여하는 지수의 액션 자체는 공격으로 취급하지 않는다. 추가 피해 500이 다시 같은 키워드를 발동시키지 않는다.

조명은 수지가 현재 양옆 아군에게 부여한다. 조명으로 발생한 재행동 및 그 연쇄에서는 조명을 재발동하지 않지만, 다른 원인의 액션은 새로 판정한다. 키워드는 소모되지 않고 턴 종료 때 삭제한다. 지우는 조명을 부여하지 않는다. 지우는 공격 역할로 +500 이후 조명 보유 아군 한 명마다 +20(강화 +30)을 차례로 더한다.

모든 이동 스킬에 공통으로, 이동 때문에 생긴 재행동·반응의 연쇄에서는 새로운 이동을 시작하지 않는다. 원래 스킬이 지시한 효빈의 두 칸 이동이나 리오네의 1번 자리까지 이동은 각 칸의 반응을 마친 뒤 계속한다. 이동 연쇄에서도 추가 피해·버프·허용된 재행동은 유지한다. 임의의 총 행동 횟수 제한을 두는 규칙은 아니다.
## 사랑의 계산

나미는 자신을 포함한 모든 아군에게 기본 2스택, 강화 후 3스택을 부여한다. 사랑은 중첩 가능·소모성·휘발성이다. 다음 공격에서 보유 스택 전체를 적용·소모하며, 공격의 데미지 증가량을 `1.1^스택 수`배로 만든다. +100은 2스택에서 +121, 3스택에서 +133.1이다. +15%p는 각각 +18.15%p와 +19.965%p다.

한 공격에 여러 증가 연산이 있으면 같은 배율을 각 증가량에 순서대로 적용한다. 예를 들어 다혜의 +50 후 +10%는 2스택에서 +60.5 후 현재 데미지 +12.1%다. 곱셈·거듭제곱으로 전체 값을 바꾸는 공격에는 이전 값에서 증가한 양을 강화한다. 지수의 보스 키워드 추가 피해나 공통 시너지 보정은 공격 고유 효과와 별도로 적용한다.

이동만 하거나 버프를 부여하는 액션에서는 소모하지 않는다. 효빈·리오네의 이동 피해 및 찬비의 아군 추가 공격도 사랑을 적용할 공격에 포함한다. 귀염둥이 7단계가 소모를 막더라도 턴 종료 삭제는 막지 않는다. 분신이 복사한 사랑 스택은 원본과 독립적으로 처리한다.

복제는 키워드 스택 부여가 아닌 분신 생성 동작이다. 인원·수명·정밀화 규칙은 [시너지 목록](synergy.md)의 복제 설명을 따른다.
