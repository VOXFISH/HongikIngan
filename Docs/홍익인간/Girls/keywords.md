# 키워드 효과 목록

2026-11-06 기준, Girl0–Girl11의 gamesystem 구현과 사용자 확인 내용을 반영한 공통 정의다. 마법소녀 문서는 아래 식별자 또는 이름을 참조한다. 부여하는 양·확률·강화는 캐릭터 문서에, 부여된 키워드의 공통 동작은 이 문서에 적는다.

## 공통 규칙

- 별도 지시나 논리적 모순이 없으면 **소모 불가·비휘발성**이다. 중첩 가능 여부는 별도로 정한다. 아직 정하지 않은 효과·수치를 임의로 채우지 않는다.
- 소모 여부와 턴 종료 삭제 여부는 독립적이다. 비휘발성은 턴이 끝나도 유지된다는 뜻이며, 다른 보스나 새 게임으로 자동 이월된다는 뜻은 아니다. 현재 구현은 새 전투에서 보스 키워드를 새로 만들고, 학교 복귀 시 아군 키워드를 지운다.
- 중첩은 같은 식별자 아래에 스택을 추가한다. 각 스택은 부여 당시 수치를 유지하며 임의의 최대 스택 제한은 없다. 중첩 불가 키워드가 이미 있으면 재부여를 무시한다.
- 키워드의 **종류 수**는 스택이 1개 이상인 서로 다른 식별자 수다. 예를 들어 표독 5스택과 검은 클로버 3스택은 2종류다.
- `+N%p`는 적용 당시 현재 합동 데미지의 N%를 더한다. 서로 다른 발동은 순서대로 계산한다. 같은 비소모성 키워드의 여러 스택은 아래에 명시한 대로 수치를 합산한다.

### 표독

가키는 액션 시 보스에게 적용된 **키워드의 종류마다 표독 1스택**, 강화 후에는 종류마다 2스택을 부여한다. 보스에게 키워드가 없으면 부여하지 않는다. 이미 존재하는 표독도 한 종류로 센다. 이번 부여량은 부여 직전 종류 수로 한 번 계산한다.

표독 3스택이면 보정 단계에 들어온 데미지 D를 `D × 1.3`으로 만든다. `D × 1.1 × 1.1 × 1.1`이 아니다. 사용한 스택은 그대로 남아 다음 턴에도 적용된다. 독설가 6단계가 활성화되어 있으면 부여량이 두 배가 되며 스택당 10%는 변하지 않는다.

### 검은 클로버

클로에는 액션마다 기본 40%, 강화 후 55% 확률로 보스에게 검은 클로버 1스택을 부여한다. 독설가 6단계에서는 확률 판정을 한 번 하고, 성공하면 2스택을 부여한다.

보스 보정 단계에서 **1스택 소모 → ×1.2 → 남은 스택이 있으면 재발동**한다. 3스택이면 `D × 1.2 × 1.2 × 1.2 = D × 1.728`이고 최종적으로 0스택이 된다. 한 발동에서 모든 스택을 한꺼번에 소모하는 방식은 아니다. 비휘발성이므로 발동하지 않고 남은 스택을 턴 종료라는 이유만으로 지우지 않는다.

귀염둥이 7단계의 소모 방지는 **아군** 키워드에만 적용한다. 보스에게 부여한 검은 클로버는 계속 소모된다.
