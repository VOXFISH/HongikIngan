# 게임 시스템 플로우차트

사용자가 제공한 전투 플로우차트 원본이다. 턴 준비, 슬롯별 공격과 트리거 처리, 데미지 계산, 합동 공격 연출, 전투 결과 판정을 나타낸다.

## 결과 분기 해석

원본 이미지에는 '보스 체력이 0 초과'에서 '교실로 복귀'와 '3턴 종료?'로 갈라지는 화살표의 참·거짓 표기가 없다. 사용자가 확인한 의도는 다음과 같다. 이미지를 수정하지 않고, 아래 규칙을 기획서에 반영했다.

| 데미지 적용 후 상태 | 다음 단계 |
| --- | --- |
| 보스 체력 0 이하 | 보스 처치, 교실로 복귀 |
| 보스 생존, 완료한 턴 수 3 미만 | 다음 턴 시작 |
| 보스 생존, 3턴 완료 | 게임 오버 |

3턴째에 보스를 처치한 경우에도 교실로 복귀한다. 보스 처치 여부를 먼저 판정하고, 보스가 살아 있을 때만 턴 제한을 확인한다.

## 문서 범위

이미지에 표시된 단계와 효과를 기획서로 옮겼다. 구체적인 수치·중첩 공식, 위치 변경 이후의 행동 횟수, 연쇄 트리거 처리 같은 미정 사항은 [기획서의 확인 항목](Game%20System%20Design.md#추가로-정해야-할-규칙)에 구분해 두었다.
