# CL01 — 학생 관리·배치·보충 학습

- 갱신일: 2026-11-05 (Asia/Seoul).
- 상태: 사용자 답변 1~14 반영. 프로토타입 해석은 별도 표시.
- 근거: [교실 기획서](../../Classroom%20System%20Design.md), [마법소녀 속성](../../Magical%20Girl%20Attributes.md).

## 결정 사항

책은 각 학생의 보유 시너지 수를 표시한다. 학생은 드래그로 순서를 바꾸며 상세 화면에서 학습·계약 해제를 이용한다. 공간 부족 시 교체 버튼으로 얼굴·이름만 표시한 보유 학생 목록을 열고 클릭한 학생을 판매한다. 재영입 시 강화는 초기화한다.

## 남은 해석·밸런싱

드래그 감도·상세 UI의 시각적 배치는 구현 선택 사항이다.

## 프로토타입 인수 기준

책 개수, 실제 슬롯 순서, 교체 판매가 지급·학생 제거, 재영입 초기화를 확인한다. 실제 실행 여부와 결과는 구현 완료 보고를 따른다.
