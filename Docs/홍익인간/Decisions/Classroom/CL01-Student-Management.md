# CL01 — 학생 관리·배치·보충 학습

- 기록일: 2026-11-05 (Asia/Seoul).
- 상태: 도표 기반 결정 + 명시된 미정 항목. 구현은 시작하지 않음.
- 근거: [교실 기획서와 원본 이미지](../../Classroom%20System%20Design.md), 기존 [마법소녀 속성](../../Magical%20Girl%20Attributes.md), 전투 진입 분기에 대한 사용자 확인.

## 결정 사항

책상에 학생을 일렬 배치하고 드래그로 순서를 교체한다. 책은 시너지 수를, 머리 위 표시는 이름·학년·표시 전용 역할군을 나타낸다. 학생 클릭 시 이름·소개·스킬 설명과 계약 해제·보충 학습을 제공한다. 계약 해제는 학년별 판매가를 반환하고, 재영입 시 강화는 초기화한다. 학습은 학년별 비용과 기존 강화 규칙을 따른다.

## 추가 결정이 필요한 사항

책 개수의 집계 기준, 학생 선택 해제와 드래그/클릭 구분, 일반 슬롯 확장 방법.

## 구현 제안과 영향 범위

전대 슬롯 순서·개체 상태·상세 UI·학년별 가격표. 거래는 잔액·대상·공간 등 필요한 조건을 먼저 검사하고 성공 시 상태와 재화를 함께 반영하도록 제안한다. 이 제안은 도표의 상세 실패 규칙을 확정하는 것은 아니다.

## 구현 후 확인 기준

학생 이동 후 표시와 순서가 일치하고, 강화 결과가 설명에 반영되며, 재영입 시 강화가 남지 않아야 한다. 현재 게임 실행 검증을 완료한 것은 아니다.
