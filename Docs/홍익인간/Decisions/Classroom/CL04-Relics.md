# CL04 — 유물 제거와 오늘의 운세

- 갱신일: 2026-11-06. 사용자 요청 및 추가 확인 반영.
- 현재 규칙: [오늘의 운세](../../Daily%20Fortune.md).

유물 제안·구매·보유 목록과 유물 효과를 제거했다. 기존 유물 UI는 운세 설명 텍스트를 표시한다. 사물함 위 누적 목록은 표시하지 않는다. 별도 구매나 전투당 한 번 제한 없이 비용을 내고 운세를 다시 뽑을 수 있다.

운세는 0.8초 연출 후 즉시 적용되며 현재 한 개만 유지한다. 게임 내 다음 날 학교로 돌아오면 미선정 상태가 된다. 목록과 가중치, 귀염둥이 효과, 영구 지급과 지속 효과의 구분은 위 문서를 따른다.

기존 파일명은 링크 호환을 위해 유지한다.
