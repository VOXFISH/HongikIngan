# CL04 — 유물 제안·획득·칠판

- 기록일: 2026-11-05 (Asia/Seoul).
- 상태: 도표 기반 결정 + 명시된 미정 항목. 구현은 시작하지 않음.
- 근거: [교실 기획서와 원본 이미지](../../Classroom%20System%20Design.md), 기존 [마법소녀 속성](../../Magical%20Girl%20Attributes.md), 전투 진입 분기에 대한 사용자 확인.

## 결정 사항

무작위 유물 제안에서 버튼을 눌러 유물을 획득하고 비용을 지불한다. 칠판에 누적 획득 유물을 표시하며 획득 후 갱신한다.

## 추가 결정이 필요한 사항

제안 개수·가격·추첨 가중치·중복 획득 허용 여부·구매 후 제안 상태.

## 구현 제안과 영향 범위

유물 보유 목록·상점 제안·경제 설정·칠판 UI. 거래는 잔액·대상·공간 등 필요한 조건을 먼저 검사하고 성공 시 상태와 재화를 함께 반영하도록 제안한다. 이 제안은 도표의 상세 실패 규칙을 확정하는 것은 아니다.

## 구현 후 확인 기준

성공한 구매가 보유 목록과 칠판에 일치하게 반영되어야 한다. 현재 게임 실행 검증을 완료한 것은 아니다.
