# CL04 — 유물 제안·획득·칠판

- 갱신일: 2026-11-05 (Asia/Seoul).
- 상태: 사용자 답변 1~14 반영. 프로토타입 해석은 별도 표시.
- 근거: [교실 기획서](../../Classroom%20System%20Design.md), [마법소녀 속성](../../Magical%20Girl%20Attributes.md).

## 결정 사항

현재 유물 제안은 3개, 개당 임시 가격 30, 보유 유물 중복 획득 불가다. 구매 후 빈 칸을 유지하고 칠판에 획득 목록을 갱신한다. 이후 유물별 가격으로 변경한다.

## 남은 해석·밸런싱

유물 풀 부족 시 가능한 개수만 제시하는 것은 프로토타입 가정이다.

## 프로토타입 인수 기준

유물 1회 구매가 한 번의 비용과 획득으로 이어지고 중복 구매가 차단되는지 확인한다. 실제 실행 여부와 결과는 구현 완료 보고를 따른다.
