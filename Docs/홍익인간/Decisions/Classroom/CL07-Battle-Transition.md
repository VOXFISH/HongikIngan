# CL07 — 전투 진입·교실 복귀

- 기록일: 2026-11-05 (Asia/Seoul).
- 상태: 도표 기반 결정 + 명시된 미정 항목. 구현은 시작하지 않음.
- 근거: [교실 기획서와 원본 이미지](../../Classroom%20System%20Design.md), 기존 [마법소녀 속성](../../Magical%20Girl%20Attributes.md), 전투 진입 분기에 대한 사용자 확인.

## 결정 사항

사용자가 확인한 흐름은 전투 버튼 → 리롤 비용 초기화 → 전투 진입이다. 원본의 마지막 교실 복귀 표기는 이 확인으로 정정한다. 기존 전투의 보스 처치 후 교실 복귀, 최대 3턴과 게임 오버 규칙을 유지한다.

## 추가 결정이 필요한 사항

미완료 펫 선택 중 전투 시작 허용 여부, 교실 재진입 시 제안 재생성·구매 상태 유지, 빈 전대의 전투 시작 여부.

## 구현 제안과 영향 범위

교실 입력·선택 세션·리롤 비용·전투 시작 상태. 거래는 잔액·대상·공간 등 필요한 조건을 먼저 검사하고 성공 시 상태와 재화를 함께 반영하도록 제안한다. 이 제안은 도표의 상세 실패 규칙을 확정하는 것은 아니다.

## 구현 후 확인 기준

전투 버튼이 교실을 다시 여는 대신 전투로 진입하고, 리롤 비용만 초기값으로 복귀해야 한다. 현재 게임 실행 검증을 완료한 것은 아니다.
