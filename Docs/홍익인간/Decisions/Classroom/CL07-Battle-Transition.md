# CL07 — 전투 진입·교실 복귀

- 갱신일: 2026-11-05 (Asia/Seoul).
- 상태: 사용자 답변 1~14 반영. 프로토타입 해석은 별도 표시.
- 근거: [교실 기획서](../../Classroom%20System%20Design.md), [마법소녀 속성](../../Magical%20Girl%20Attributes.md).

## 결정 사항

학교와 전투는 별도 씬이다. 전투 버튼은 리롤 비용을 20으로 초기화하고 전투로 진입한다. 빈 전대와 미완료 펫 선택 중에는 전투 시작을 제한한다. 승리 후 학교 복귀 시 상점 제안을 새로 생성한다. 씬 사이에 진행 상태와 SoundManager를 유지한다. BGM/SFX/Voice별 볼륨과 음소거를 제공한다.

## 남은 해석·밸런싱

FMOD 뱅크·이벤트 연결과 실행 검증은 구현 담당자가 실제 환경을 확인하여 보고한다.

## 프로토타입 인수 기준

씬 왕복 후 상태 유지, 전투 시작 제한, SoundManager 중복 방지와 3채널 독립 제어를 확인한다. 실제 실행 여부와 결과는 구현 완료 보고를 따른다.
