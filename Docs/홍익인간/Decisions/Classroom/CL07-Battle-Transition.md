# CL07 — 전투 진입·교실 복귀

- 갱신일: 2026-11-06 (Asia/Seoul).
- 상태: 사용자 답변 1~14 반영. 프로토타입 해석은 별도 표시.
- 근거: [교실 기획서](../../Classroom%20System%20Design.md), [마법소녀 속성](../../Magical%20Girl%20Attributes.md).

## 결정 사항

학교와 전투는 별도 씬이다. 전투 버튼은 현재 운세를 유지하고 전투로 진입한다. 운세 연출 중에는 진입하지 못한다. 빈 전대와 미완료 펫 선택 중에는 전투 시작을 제한한다. 전투 보상 수령 후 다음 날 학교 복귀 시 운세를 미선정 상태로, 리롤 기본 비용을 20으로 초기화한다. 이미 지급된 에너지·영구 강화는 유지한다. 상세는 [오늘의 운세](../../Daily%20Fortune.md)를 따른다. 사용하지 않은 펫은 유지한다. 씬 사이에 진행 상태와 SoundManager를 유지한다. BGM/SFX/Voice별 볼륨과 음소거를 제공한다.

## 남은 해석·밸런싱

FMOD 뱅크·이벤트 연결과 실행 검증은 구현 담당자가 실제 환경을 확인하여 보고한다.

## 프로토타입 인수 기준

씬 왕복 후 상태 유지, 전투 시작 제한, SoundManager 중복 방지와 3채널 독립 제어를 확인한다. 실제 실행 여부와 결과는 구현 완료 보고를 따른다.
