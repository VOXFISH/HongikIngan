# CL03 — 일반 모집

- 갱신일: 2026-11-05 (Asia/Seoul).
- 상태: 사용자 답변 1~14 반영. 프로토타입 해석은 별도 표시.
- 근거: [교실 기획서](../../Classroom%20System%20Design.md), [마법소녀 속성](../../Magical%20Girl%20Attributes.md).

## 결정 사항

후보 3명, 학년 가중치 4:2:0.5다. 후보 묶음 내 중복 금지·보유 학생 제외를 적용한다. 영입은 잔액·공간·중복 여부를 검사하고 학년별 결제와 학생 추가를 함께 수행한다. 공간 부족 시 교체 판매를 제공한다. 구매 칸은 리롤까지 비워 둔다.

## 남은 해석·밸런싱

유효 후보 부족 시 가능한 인원만 표시하고 학년 내 균등 추첨하는 것은 프로토타입 가정이다.

## 프로토타입 인수 기준

후보 중복·보유 학생·정원 초과 방지와 결제 실패 시 상태 보존을 확인한다. 실제 실행 여부와 결과는 구현 완료 보고를 따른다.
