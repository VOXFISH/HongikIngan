# CL03 — 일반 모집 제거

- 갱신일: 2026-11-05. 사용자 추가 요청으로 기존 일반 모집 결정을 대체.
- 근거: [교실 기획서](../../Classroom%20System%20Design.md).

학생 세 명을 진열하고 개별 구매하던 상점은 제거한다. 시작 학생 지급은 유지하되 플레이 중 영입 경로는 펫 후보 선택 하나로 통일한다. 영입비는 펫 사용 비용에 포함되므로 학년별 별도 영입비를 받지 않는다.

기존 학생 판매·학습·책상 배치와 펫 선택 중 교체 판매는 유지한다. `RecruitOffers`와 `BuyRecruit` 및 일반 모집 UI를 제거하고 모든 호출부·검사를 펫 방식으로 바꾼다. 경제 에셋의 기존 영입 가격은 호환을 위해 남기지만 사용하지 않는다.

검증 기준: 일반 모집 화면·구매 경로 없음, 펫 후보 중복/보유 학생 제외, 펫을 통한 재영입 시 강화 초기화.
