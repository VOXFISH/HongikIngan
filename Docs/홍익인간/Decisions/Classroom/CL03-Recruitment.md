# CL03 — 일반 모집

- 기록일: 2026-11-05 (Asia/Seoul).
- 상태: 도표 기반 결정 + 명시된 미정 항목. 구현은 시작하지 않음.
- 근거: [교실 기획서와 원본 이미지](../../Classroom%20System%20Design.md), 기존 [마법소녀 속성](../../Magical%20Girl%20Attributes.md), 전투 진입 분기에 대한 사용자 확인.

## 결정 사항

학생 후보 3명을 이름·사진으로 표시한다. 학년 가중치는 4:2:0.5다. 클릭 시 시너지·스킬·가격·영입 버튼을 표시하고 공간이 있으면 학년별 비용으로 영입한다. 기존 중복 영입 금지는 유지한다.

## 추가 결정이 필요한 사항

후보 내 중복 및 보유 학생 노출 여부, 학년 내 추첨 방식, 후보 부족, 잔액·공간 부족 UI, 구매 후 후보 보충.

## 구현 제안과 영향 범위

캐릭터 원본·보유 학생·현재 슬롯·경제 설정. 거래는 잔액·대상·공간 등 필요한 조건을 먼저 검사하고 성공 시 상태와 재화를 함께 반영하도록 제안한다. 이 제안은 도표의 상세 실패 규칙을 확정하는 것은 아니다.

## 구현 후 확인 기준

3개 후보의 정보와 비용이 일치하고, 중복 영입 및 정원 초과가 발생하지 않아야 한다. 현재 게임 실행 검증을 완료한 것은 아니다.
