# CL02 — 리롤

- 갱신일: 2026-11-05 (Asia/Seoul).
- 상태: 사용자 답변 1~14 반영. 프로토타입 해석은 별도 표시.
- 근거: [교실 기획서](../../Classroom%20System%20Design.md), [마법소녀 속성](../../Magical%20Girl%20Attributes.md).

## 결정 사항

리롤 초기 비용 20, 증가량 20이다. 성공 시 유물·학생·펫 제안을 함께 갱신하고 다음 비용이 증가한다. 구매한 칸은 즉시 보충하지 않는다. 전투 진입 시 비용을 20으로 초기화하고 승리 후 학교 복귀 시 제안을 새로 생성한다. 미완료 펫 선택 중에는 리롤을 제한한다.

## 남은 해석·밸런싱

잔액 부족 시 거래 실패 표시 방식은 구현 선택 사항이다.

## 프로토타입 인수 기준

20→40→60 결제와 성공 시에만 증가, 보유 상태 보존, 세 패널 갱신을 확인한다. 실제 실행 여부와 결과는 구현 완료 보고를 따른다.
