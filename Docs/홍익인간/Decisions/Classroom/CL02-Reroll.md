# CL02 — 리롤

- 기록일: 2026-11-05 (Asia/Seoul).
- 상태: 도표 기반 결정 + 명시된 미정 항목. 구현은 시작하지 않음.
- 근거: [교실 기획서와 원본 이미지](../../Classroom%20System%20Design.md), 기존 [마법소녀 속성](../../Magical%20Girl%20Attributes.md), 전투 진입 분기에 대한 사용자 확인.

## 결정 사항

리롤 비용을 지불한 후 비용을 증가시킨다. 랜덤 유물·일반 모집·펫 제안을 함께 갱신한다. 전투 버튼 입력 시 비용을 초기값으로 되돌린다.

## 추가 결정이 필요한 사항

초기 비용·증가량 또는 증가식, 구매 제안 보충, 펫 선택 중 리롤, 후보 풀이 부족할 때 처리.

## 구현 제안과 영향 범위

경제 설정·상점 제안·진행 중인 선택 상태. 거래는 잔액·대상·공간 등 필요한 조건을 먼저 검사하고 성공 시 상태와 재화를 함께 반영하도록 제안한다. 이 제안은 도표의 상세 실패 규칙을 확정하는 것은 아니다.

## 구현 후 확인 기준

리롤마다 결제는 한 번, 세 패널은 갱신되고 보유 학생·유물은 유지되어야 한다. 현재 게임 실행 검증을 완료한 것은 아니다.
