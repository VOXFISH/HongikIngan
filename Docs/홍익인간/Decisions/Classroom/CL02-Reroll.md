# CL02 — 유물 전용 리롤

- 갱신일: 2026-11-05. 일반 모집 제거·펫 즉시 보충 추가 요청 반영.
- 근거: [교실 기획서](../../Classroom%20System%20Design.md).

리롤은 유물 한 칸만 바꾼다. 비용은 20부터 시작해 성공할 때마다 20 증가하며 전투 진입 시 초기화한다. 펫 세 칸과 보유 학생·사진·유물은 유지한다. 후보가 둘 이상이면 직전과 다른 유물을 고르고, 하나뿐이면 같은 유물이 나올 수 있다.

구매 완료, 유물 후보 없음, 미완료 펫 선택, 잔액 부족일 때는 리롤과 비용 증가를 모두 막는다. 구매 제한은 리롤로 풀리지 않으며 전투 승리 후 교실 복귀 시 갱신한다.

검증 기준: 유물 한 칸 갱신과 펫 보존, 성공 시에만 결제·비용 증가, 구매 후 리롤 거절 시 상태 보존.
