# CL02 — 오늘의 운세 리롤

- 갱신일: 2026-11-06. [오늘의 운세](../../Daily%20Fortune.md)를 따른다.

유물 리롤을 제거하고 운세 리롤로 대체한다. 기본 비용은 20부터 시작해 성공할 때마다 20 증가한다. 현재 운세의 할인과 귀염둥이 9단계 무료 상점을 결제 전에 적용한다. 리롤 후 별도 구매 없이 0.8초 연출이 끝나면 결과가 즉시 적용된다. 연출 중 버튼·학교 거래·전투 진입은 잠긴다.

가중치는 16종 목록을 그대로 사용하며 같은 운세 재등장도 허용한다. 귀염둥이 5·7단계는 꽝을 제외한다. 재추첨은 기존 지속 효과를 교체하며 지급된 에너지·영구 강화는 회수하지 않는다. 펫·사진·보유 학생은 유지한다.

게임 내 다음 날 학교 복귀 시 운세와 기본 비용을 초기화한다. 펫 선택 중·잔액 부족·전투 중·리롤 중 요청은 결제하지 않는다.
