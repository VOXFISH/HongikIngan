# CL05 — 펫 영입·시너지 추첨·폴라로이드

- 기록일: 2026-11-05 (Asia/Seoul).
- 상태: 도표 기반 결정 + 명시된 미정 항목. 구현은 시작하지 않음.
- 근거: [교실 기획서와 원본 이미지](../../Classroom%20System%20Design.md), 기존 [마법소녀 속성](../../Magical%20Girl%20Attributes.md), 전투 진입 분기에 대한 사용자 확인.

## 결정 사항

무작위 펫 제안 3개를 생성한다. 일반/고급/최고급/시너지 펫 비율은 40/30/10/20%, 비용은 30/50/100/60이다. 후보→선택 인원은 3→1, 5→1, 5→2, 3→1이다. 앞의 세 종류는 학년 가중치 4:2:0.5를 사용한다. 시너지 펫은 보유 시너지 비율로 시너지를 고르고 특수 시너지는 제외한다. 선택 종료 또는 영입 포기 시 미영입 후보의 폴라로이드를 등록한다.

## 추가 결정이 필요한 사항

펫 비용 외 학년별 비용 추가 여부, 포기 환불, 부분 선택·정원 부족, 펫/학생 후보 중복, 시너지 비율 산식·빈 풀 대안, 시너지 펫의 학년 가중치 적용, 사진 중복 누적 여부, 최고급 10% 뒤 생략 부호 의미.

## 구현 제안과 영향 범위

펫 제안·후보 선택 세션·보유 시너지·학생 보유 목록·폴라로이드 목록·경제 설정. 거래는 잔액·대상·공간 등 필요한 조건을 먼저 검사하고 성공 시 상태와 재화를 함께 반영하도록 제안한다. 이 제안은 도표의 상세 실패 규칙을 확정하는 것은 아니다.

## 구현 후 확인 기준

펫별 후보/선택 수와 특수 시너지 제외를 지키고, 선택한 학생의 사진을 미영입 사진으로 등록하지 않아야 한다. 현재 게임 실행 검증을 완료한 것은 아니다.
