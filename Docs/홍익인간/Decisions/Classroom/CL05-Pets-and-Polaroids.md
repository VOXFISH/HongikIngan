# CL05 — 펫 영입·시너지 추첨·폴라로이드

- 갱신일: 2026-11-05 (Asia/Seoul).
- 상태: 사용자 답변 1~14 반영. 프로토타입 해석은 별도 표시.
- 근거: [교실 기획서](../../Classroom%20System%20Design.md), [마법소녀 속성](../../Magical%20Girl%20Attributes.md).

## 결정 사항

펫 비용에 영입비를 포함하고 후보를 보기 전에 결제한다. 초기 세 칸은 40/30/10/20%로 독립 추첨하여 종류 중복을 허용하되 일반 펫 3개면 전체 재추첨한다. 후보에는 중복·보유 학생이 없다. 시너지 가중치는 특수 시너지를 제외한 보유 학생 수이며 유효 시너지가 없으면 일반 후보 추첨으로 대체하고 학년 가중치도 적용한다. 사진은 미영입 후보에 대해 중복 누적하며 총 장수를 전투에 사용한다. 사용자 추가 확인대로 최고급 포함 최대 1명만 선택하며, 포기 시 환불하지 않는다.

일반 학생 모집은 제거하고 새 학생 영입은 펫으로만 제공한다. 펫 결제가 성공하면 사용한 칸만 즉시 보충한다. 보충 결과 일반 펫 세 개가 되면 그 칸만 재추첨하고 다른 칸은 유지한다. 같은 종류가 다시 나올 수 있다. 리롤·전투 복귀는 펫을 갱신하지 않는다. 결제 실패·학생 후보 부족 시 보충하지 않으며 현재 선택이 끝날 때까지 보충된 펫도 사용할 수 없다.

## 남은 해석·밸런싱

펫 선택 중 교체 판매는 입력 제한의 예외다. 후보 풀 부족 시 가능한 인원만 표시하는 세부 방식은 프로토타입 가정이다.

## 프로토타입 인수 기준

선결제·사용한 칸만 즉시 보충·다른 펫 유지·선택 중 중복 구매 방지·추가 영입비 없음·최대 1명 선택·미영입 사진만 누적·일반 펫 3개 재추첨·시너지 빈 풀 대체를 확인한다. 실제 실행 여부와 결과는 구현 완료 보고를 따른다.
