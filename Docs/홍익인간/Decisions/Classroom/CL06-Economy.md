# CL06 — 경제 설정·결제

- 갱신일: 2026-11-05 (Asia/Seoul).
- 상태: 사용자 답변 1~14 반영. 프로토타입 해석은 별도 표시.
- 근거: [교실 기획서](../../Classroom%20System%20Design.md), [마법소녀 속성](../../Magical%20Girl%20Attributes.md).

## 결정 사항

경제 값은 단일 ScriptableObject에서 관리한다. 유물 리롤 20/+20, 펫 비용 30/50/100/60, 현재 유물 가격 30을 적용한다. 펫 비용에 학생 영입비를 포함하며 일반 모집의 별도 영입비는 사용하지 않는다. 기존 영입 가격 필드는 에셋 호환성을 위해 보존한다. 보충 학습과 계약 해제는 기존 학년별 강화비·판매가를 사용한다. 유물 구매 후 또는 남은 유물이 없을 때는 리롤 비용을 차감하지 않는다.

## 남은 해석·밸런싱

학년별 가격 및 유물별 최종 가격은 추후 밸런싱 대상이다. 포기 환불 정책의 해석은 CL05를 따른다.

## 프로토타입 인수 기준

각 거래가 잔액·소유권·공간 검사를 통과한 경우에만 한 번 반영되는지 확인한다. 실제 실행 여부와 결과는 구현 완료 보고를 따른다.
