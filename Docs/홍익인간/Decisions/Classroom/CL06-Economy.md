# CL06 — 경제 설정·결제

- 기록일: 2026-11-05 (Asia/Seoul).
- 상태: 도표 기반 결정 + 명시된 미정 항목. 구현은 시작하지 않음.
- 근거: [교실 기획서와 원본 이미지](../../Classroom%20System%20Design.md), 기존 [마법소녀 속성](../../Magical%20Girl%20Attributes.md), 전투 진입 분기에 대한 사용자 확인.

## 결정 사항

경제값은 단일 ScriptableObject로 관리한다. 학년별 영입/학습/판매 가격, 펫 비용, 유물 가격, 리롤 비용을 구분한다. 펫 비용은 이번 도표 값이고 학년 가격 예시는 여전히 임시다.

## 추가 결정이 필요한 사항

실제 학년별 가격·유물 가격·리롤 초기값과 증가식. 펫 추가 비용과 환불은 CL05에서 결정한다.

## 구현 제안과 영향 범위

EconomySettings·현재 재화·각 거래 기능. 거래는 잔액·대상·공간 등 필요한 조건을 먼저 검사하고 성공 시 상태와 재화를 함께 반영하도록 제안한다. 이 제안은 도표의 상세 실패 규칙을 확정하는 것은 아니다.

## 구현 후 확인 기준

같은 학년의 학생은 동일 가격표를 참조하고, 가격 수정이 개별 캐릭터 수동 수정 없이 반영되어야 한다. 현재 게임 실행 검증을 완료한 것은 아니다.
