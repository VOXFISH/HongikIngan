# CL06 — 경제 설정·결제

- 갱신일: 2026-11-06.
- 근거: [오늘의 운세](../../Daily%20Fortune.md), [교실 기획서](../../Classroom%20System%20Design.md).

경제 기본값은 단일 EconomySettings에서 관리한다. 운세 리롤 기본 비용 20/+20, 펫 비용 30/50/100/60을 적용한다. 유물 구매 가격 필드는 제거했다. 학년별 학습·판매와 책상 확장 비용은 유지한다.

운세 할인은 실제 결제와 UI 표시 모두 PrototypeRun의 가격을 사용한다. 귀염둥이 9단계는 운세 리롤·모집·보충 학습·책상 확장 비용을 0으로 한다. 할인은 판매 수입에 적용하지 않는다. 재화 부족이나 선택 잠금 시 결제·다음 비용 증가를 수행하지 않는다.

전투 보상 운세는 기본 50 + 잔여 턴×100 + 정산 전 에너지의 10%에 배율을 적용하고 소수를 버린 뒤 선도부 획득 배율을 적용한다. 보상은 정산 스냅샷으로 고정하고 한 번 수령한다.
