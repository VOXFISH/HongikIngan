## 확정 제약

characterId를 기준으로 중복 영입을 금지한다. 가격은 학년별로 공통이며 역할군은 표시 전용이다. 캐릭터 체력(HP)·방어력·치명타·속도는 존재하지 않는다. 강화는 현재 변수 값을 교체하고 공유 원본은 변경하지 않는다.
