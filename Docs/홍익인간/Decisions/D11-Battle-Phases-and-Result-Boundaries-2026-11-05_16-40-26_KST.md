## 확정 제약

보스를 처치하면 교실로 복귀한다. 보스가 살아 있으면 최대 세 턴까지 진행하며, 세 번째 턴에도 승리 판정을 우선한다. 보상과 다음 스테이지 진행은 현재 범위 밖이다.

## 권고안

초기화 → 준비 → 입력 잠금 → 추가 슬롯·인원 반영 → 배치 → 액션·반응 → 폴라로이드 → 보스 키워드 → 영창·빔 → 데미지 한 번 적용 → 완료 턴 집계와 결과 판정 순으로 처리한다. 시너지는 영창 직전에 집계한다.
