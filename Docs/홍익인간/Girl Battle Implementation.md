## 계산과 이동

- 모든 `+%p`는 효과 발생 당시의 현재 합동 데미지 증가다. 20%p 두 번은 ×1.2를 두 번 적용한 결과이며, 별도 가산 배율 풀로 누적하지 않는다.
- 자기 차례를 계기로 하는 효빈·리오네의 자발적 이동은 턴당 한 묶음이다. 이동으로 자기 액션이 다시 실행되어도 이동 묶음을 새로 만들지 않는다. 다른 소녀에게 밀려 이동한 경우에도 이동 효과는 발동한다.
- 한 칸 교환 → 새 자리 순서대로 이동 효과 → 작은 번호와 큰 번호의 재행동 → 다음 한 칸 순으로 처리한다. 찬비의 각 아군 추가 공격은 액션 반응과 시너지를 발생시키며, 해당 아군의 고유 스킬을 대신 재사용하는 것은 아니다.
- 아이린의 4번 조건은 매번 액션 실행 시 현재 자리를 확인한다. 4번에서 공격한 뒤 효빈에게 밀려 5번에서 재행동하면 추가 공격에는 3배가 없다.
- 키워드가 전혀 없는 보스에게 가키가 행동하면 표독을 부여하지 않는다. 이미 표독이 있다면 표독 자체도 한 종류로 센다.
- 표독은 스택당 받는 피해 +10%p, 중첩 가능·소모 불가·비휘발성이다. 보스 보정 시 전체 스택의 수치를 합산한다.
- 검은 클로버는 중첩 가능·소모성·비휘발성이다. 보스 보정 시 한 스택을 소모해 ×1.2를 적용하고, 남은 스택이 있으면 다시 발동한다. 보스 교체 시 보스 키워드는 새 전투 상태로 교체한다.

## 공통 시너지

공통 정의의 전체 목록과 상세 적용 조건은 [시너지 효과 목록](Girls/synergy.md), 소모·중첩·유지 규칙은 [키워드 효과 목록](Girls/keywords.md)에서 관리한다.

별도 누적 명시가 없으면 충족한 최고 인원 단계 하나만 적용한다. 기존의 임시 `부활동 인원당 +20` 효과는 제거했다. 이번 범위에 없는 천문부·미술부·연극부의 신규 효과는 이 구현에 포함하지 않는다.

분위기는 전투·학교를 넘어 현재 게임에 누적하고 새 게임에서 초기화한다. 분위기 1마다 최종 데미지 +1%p. 100 이상이면 마지막 소녀의 액션 효과 뒤 현재 합동 데미지 +50%p, 300 이상이면 해당 마지막 소녀의 액션을 추가로 한 번 실행한다. 이 시너지의 추가 행동은 턴당 한 번이며 마지막 자리의 소녀가 바뀌어도 갱신되지 않는다. 다른 원인의 재행동을 막지 않는다.

500 이상이면 현재 마지막 소녀가 이미 가진 각 시너지의 인원 계산에 1을 더한다. 5000 이상이면 위 대상 효과를 모든 소녀에게 적용하고, 분위기 추가 행동은 각 소녀당 턴에 한 번이다. 높은 임계값은 낮은 임계값 효과를 함께 유지한다.

사랑꾼의 전투 시작 배치는 Battle 씬에서 배치를 마치고 첫 공격을 시작할 때 확정한다. 이후 이동·재배치로 해당 전투의 저장 보너스는 바뀌지 않는다. 최종 보정은 폴라로이드 → 운동부 → 사진부 → 반항아 → 분위기 → 사랑꾼 → 유물 → 보스 키워드 순서다. 승리 종료 재화는 승리 보상 지급 후 선도부 종료 효과를 적용하며, 패배 종료 효과는 세 번째 턴 결과 때 적용한다. 종료 효과는 전투마다 한 번이다.

귀염둥이 9명은 최고 단계 하나 원칙에 따라 모든 유물 두 번만 적용하고, 7명의 키워드 소모 방지를 별도로 유지하지 않는다.

선도부 획득 배율은 액션 재화·학생 판매·승리 보상·종료 보상 모두에 적용한다. 정수 재화의 소수 부분은 버린다. 최고 단계 하나 규칙에 따라 6명은 별도 획득 배율 없이 종료 시 보유 재화 두 배를 적용한다. 현재 여섯 유물에는 디버프 관련 유물이 없으므로 귀염둥이 5명의 해당 부분은 대상이 없다. 유물의 `DebuffRelated` 분류로 추가할 수 있다.

## 이동 연쇄와 사진부 확장

이동이 만든 재행동·반응의 연쇄에서는 새로운 이동을 시작하지 않는다. 원래 지정한 복수 칸 이동은 계속한다. 조명으로 발생한 재행동 연쇄에서는 조명을 다시 발동하지 않는다. 정윤의 분신은 스킬·강화·키워드·시너지를 복사하고 대상 바로 뒤에 배치되며 복제 스킬은 사용할 수 없다. 일반 인원은 최대 7명, 분신 포함 최대 9명이다. 정밀화의 성공 횟수는 정윤 보유 상태에 누적하고 새 게임·재획득 때 초기화한다.

## Girl17 확장 실행과 검증

2026-11-06, Unity 6000.3.7f1 컴파일·씬 참조 검사·Windows 빌드를 통과했다. 자동 규칙 검사 2,260개, 콘텐츠·시너지 검사 833개, 사진부·사랑·복제·이동 연쇄 검사 405개로 총 3,498개 assertion을 통과했다. 시작 인원은 2,000개 시드에서 100 에너지, 중복 없는 1·2학년 3명, 재현 가능한 추첨과 학년 비율을 확인했다.

실제 플레이어 검증도 통과했다: 메인 버튼과 학교→전투·새 게임·프로그램 종료 14개, 18명 표시·강화·사진부 분신·학교 복귀 109개, 기존 전투 UI 26개, 펫·유물 거래 35개. 사진부 전투와 분신 카드 캡처에서 이름·학년·역할군·시너지·스킬 표시를 확인했다. 숨김 실행의 일부 초기 학교 캡처는 검게 출력되어 해당 캡처로 시각 판정을 하지 않았고, 1440×900에서 학교 주요 버튼의 화면 내 위치는 자동 검사로 확인했다. 수동 마우스 인수 검사와 FMOD 실제 재생은 수행하지 않았다.

재현: 배치 빌드 `HongikIngan.Editor.PrototypeBuilder.Build`로 규칙 검증과 빌드를 실행한다. 플레이어에 `--main-flow-smoke`, `--girl-battle-smoke`, `--battle-ui-smoke`, `--school-economy-smoke` 중 하나와 `--smoke-output <폴더>`를 전달한다. 검증용 재화·보스 수치는 해당 실행에서만 변경한다. 로컬 로그는 `UnityProject/Logs/Girl18FinalBuild.log`, `Girl18MainSmoke.log`, `Girl18BattleSmoke.log`, `Girl18UiRegression.log`, `Girl18SchoolRegression.log`다. 결과와 캡처는 `UnityProject/Builds/`의 같은 이름 폴더에 있으며 로그·빌드는 커밋하지 않는다.

아래 수치는 Girl0–Girl11 구현 시의 검증 이력이다. Girl17 확장 검증 결과와 구별한다.

Unity 6000.3.7f1의 최종 규칙 검사 2,260개와 새 콘텐츠 검사 661개, Windows 빌드를 통과했다. 실제 플레이어에서 12명 표시·강화·전투 진행·학교 복귀 검사 67개, 기존 전투 UI 검사 26개와 펫·유물 검사 33개를 통과했다. 1440×900 운동부와 1280×720 선도부 화면을 확인했다. 수동 마우스 인수 검사와 FMOD 실제 재생은 이번에 수행하지 않았다.

재현: 에디터 `HongikIngan.PrototypeChecks.Run` 또는 배치 빌드 `HongikIngan.Editor.PrototypeBuilder.Build`. 플레이어 인수 `--girl-battle-smoke --smoke-output <폴더>`는 검사용으로 재화·진행을 구성하고 보스 체력을 낮추며, 일반 실행 설정은 바꾸지 않는다. 결과 파일 `girl-battle-result.txt`와 두 PNG를 출력한다. 로컬 로그는 `UnityProject/Logs/GirlsBuildFinal.log`, `GirlBattleSmokeFinal.log`, `GirlBattleRegression.log`, `GirlSchoolRegressionFinal.log`에 있다. 로그·빌드는 커밋하지 않는다.

## Girl18–Girl35 확장

이 절은 이전 18명 구현 범위 설명보다 우선한다. 전체 36명의 이름·학년·역할군·시너지·스킬·강화를 구현했다. Girl23의 제목 이름은 민영, Girl35는 드미트리우스이며 스킬은 스파르타!!다. Girl18–Girl35의 JSON 모양 블록은 자연어와 사용자 답변에 맞춘 한글 요약으로 교체했다. 상세 수치와 동작은 각 Girl 문서 및 [시너지](Girls/synergy.md), [키워드](Girls/keywords.md)에 기록한다.

새로운 미술부·천문부 액션은 `ExpansionActions`가 담당하고, 행동 큐·이동 연쇄·재행동 원인은 `BattleActionResolver`가 관리한다. `PrototypeRun`은 누적 별의 힘, 게임당 1회 수현 방어, 정원과 보상 스냅샷을 관리한다. 커피는 턴 시작에 처리하고, 수현의 방어는 보스 처치로 위장하지 않는 `Saved` 결과로 구분한다.

세아는 이전 이동·원위치 복귀 스킬을 폐기하고 데미지 10부터 강화할 때마다 x2로 바뀐다. 보충 학습은 같은 학교 방문 중 여러 번 가능하며 비용을 매번 지불한다. 미네 강화는 별의 힘 x2만큼 커피를 부여한다. 미감은 자기 스택을 기준으로 1스택씩 사용하고 가영의 재사용 부여 대상은 양옆이다.

모집에서는 정원을 초과해 영입할 수 있다. 모집 창의 계약해제 버튼·패널을 삭제했으며, 정리 작업은 학교의 학생 상세 창에서 한다. 보유 인원이 출전 정원을 초과하면 전투 시작 버튼과 모델 명령이 모두 거부한다. 9명을 넘는 보유 학생도 학교의 학생 페이지 버튼으로 관리한다. 혜림은 현재 열린 정원에서 기본 2/강화 3명을 빼며 출전 턴은 4/5턴이다.

비게임오버 전투 종료 시 정산 직전 에너지와 남은 턴을 저장한다. `50 + 남은 턴 x100 + 저장 에너지의 10%`에 기존 유물과 획득 배율을 반영하며, 수령 버튼을 누를 때 한 번만 지급한다. 수령 뒤 종료 시너지를 적용하고 다음 학교로 간다. `BattleRewardPopup`은 씬에 저장된 네모 창·TMP 텍스트·버튼을 표시만 하며 RectTransform을 변경하지 않는다. 수현의 방어 결과도 같은 수령 흐름을 사용한다.

## 2026-11-06 최종 병합 검증

Girl35는 다른 개발자의 최신 이름 변경과 사용자 확인을 반영해 드미트리우스로 통일했다. 확정된 스파르타!!의 효과·강화는 유지하고, 중복 뭉치 문서를 제거했다. 최신 main의 학교 책상·시너지 책 프리팹과 번호 라벨 변경을 보존해 병합했다. 충돌한 AI 기록과 UI 편집 문서는 양쪽 내용을 모두 보존했다.

Unity 6000.3.7f1에서 규칙 검사 4,000개(기본 2,261, 기존 소녀 833, 사진부 405, 정산 22, 확장 479)와 초기 지급 2,000개 시드 검사, 씬 참조 검증 및 Windows 빌드를 통과했다. 정산 계산·중복 수령 방지·게임오버 제외·수현 방어와 종료 직전 시너지 인원 보존도 검사한다. 로그는 `UnityProject/Logs/Girl35MergedBuild.log`에 있으며 생성 빌드·로그는 버전 관리에서 제외한다.

기존 폰트에 없는 일부 장식 기호(별 아이콘 등)의 대체 표시 경고가 남아 있다. 보상 팝업은 지원되는 문자로 표시한다. 수동 마우스 인수 검사와 FMOD 실제 재생은 수행하지 않았다.

실제 플레이어에서 UI 54개와 전체 소녀 전투·표시 258개 검사를 통과했다. 전투 카드 이름의 잘림 여부도 검사한다. 캡처는 Girl35MergedMockup, Girl35NameFitRoster에 있으며 이름 크기 수정 후 빌드는 Logs/Girl35NameFitBuild.log에 기록했다.

추가로 main의 c5b250e 전투 카드·배경 건물 프리팹 변경을 사용자 승인에 따라 통합했다. 새 프리팹 구조에 보상 팝업과 이름 Auto Size를 적용한 최종 빌드에서도 같은 규칙 4,000개·시드 2,000개·플레이어 312개 검사가 통과했다. 최종 로그는 Logs/Girl35PrefabMergedBuild.log, Girl35PrefabMockupPlayer.log, Girl35PrefabRosterPlayer.log이며 캡처와 결과는 Builds/Girl35PrefabMockup 및 Girl35PrefabRoster에 있다.
