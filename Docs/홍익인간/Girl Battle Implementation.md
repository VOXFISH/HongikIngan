# Girl0–Girl11 전투 구현

기준: 2026-11-06 사용자 요청과 추가 답변. 원래 작업 폴더의 `Docs/홍익인간/Girls/Girl0_*.md`부터 `Girl11_*.md`까지 최신 편집 내용을 읽고 gamesystem에 구현했다. JSON보다 제목·파일명과 하단 자연어를 우선하며, 자연어가 없는 부분만 JSON을 참고했다. JSON 내부의 중복 식별자는 제목의 Girl 번호로 교정했고, 미정 수치·연산·시너지 적용 조건은 사용자 답변으로 확정했다. 원본 문서의 배경·외모·연출 설정은 구현 범위에 포함하지 않았다.

가키는 원문에 별도 스킬 이름이 없어 효과를 설명하는 `표독 부여`로 표시한다. 가람의 `지도자`는 `리더`로 통일했다. 아이린은 JSON 내 0·40·80의 충돌을 사용자 확인으로 40→80으로 해결했다. 민지는 JSON의 반항아 부재 조건을 사용하지 않고 자연어의 인원수 공격을 사용한다. 두 수치가 함께 바뀌는 다혜는 사용자 확인에 따라 한 번의 강화로 +100/15%를 적용한다.

## 계산과 이동

- 모든 `+%p`는 효과 발생 당시의 현재 합동 데미지 증가다. 20%p 두 번은 ×1.2를 두 번 적용한 결과이며, 별도 가산 배율 풀로 누적하지 않는다.
- 자기 차례를 계기로 하는 효빈·리오네의 자발적 이동은 턴당 한 묶음이다. 이동으로 자기 액션이 다시 실행되어도 이동 묶음을 새로 만들지 않는다. 다른 소녀에게 밀려 이동한 경우에도 이동 효과는 발동한다.
- 한 칸 교환 → 새 자리 순서대로 이동 효과 → 작은 번호와 큰 번호의 재행동 → 다음 한 칸 순으로 처리한다. 찬비의 각 아군 추가 공격은 액션 반응과 시너지를 발생시키며, 해당 아군의 고유 스킬을 대신 재사용하는 것은 아니다.
- 아이린의 4번 조건은 매번 액션 실행 시 현재 자리를 확인한다. 4번에서 공격한 뒤 효빈에게 밀려 5번에서 재행동하면 추가 공격에는 3배가 없다.
- 키워드가 전혀 없는 보스에게 가키가 행동하면 표독을 부여하지 않는다. 이미 표독이 있다면 표독 자체도 한 종류로 센다.
- 표독은 스택당 받는 피해 +10%p, 중첩 가능·소모 불가·비휘발성이다. 보스 보정 시 전체 스택의 수치를 합산한다.
- 검은 클로버는 중첩 가능·소모성·비휘발성이다. 보스 보정 시 한 스택을 소모해 ×1.2를 적용하고, 남은 스택이 있으면 다시 발동한다. 보스 교체 시 보스 키워드는 새 전투 상태로 교체한다.

## 이 12명이 가진 공통 시너지

별도 누적 명시가 없으면 충족한 최고 인원 단계 하나만 적용한다. 기존의 임시 `부활동 인원당 +20` 효과는 제거했다. 이번 로스터에 없는 천문부·미술부·연극부·사진부의 신규 효과는 이 구현에 포함하지 않는다.

| 시너지 | 효과 |
| --- | --- |
| 운동부 | 2명 +200, 3명 +400, 4명 +800 후 ×2, 5명 +1600 후 ×10, 6명 +500000 후 ×10 |
| 선도부 | 2명 모든 재화 획득 ×1.5, 3명 ×2, 4명 ×2와 전투 종료 +100, 6명 전투 종료 시 보유 재화 ×2 |
| 리더 | 리더가 버프를 적용한 직후 현재 합동 데미지 +30%. 리오네의 이동 버프와 가람의 반항아 기반 버프에 연결 |
| 분위기메이커 | 해당 소녀 액션마다 분위기 증가: 1명 +30, 3명 +50, 5명 +100, 9명 +1000 |
| 반항아 | 2명 해당 소녀 액션 두 번·최종 데미지 ×0.7. 5명 해당 소녀 액션마다 뒤로 이동·최종 데미지 ×0.1 |
| 사랑꾼 | 전투 시작 배치에서 인접한 연결 묶음의 사랑꾼 인원당 +100%를 보너스로 저장하고 최종 공격에 적용. 떨어진 단독 사랑꾼은 제외 |
| 독설가 | 3명 약화 역할군 액션마다 ×1.2. 6명 같은 효과와 모든 디버프 부여 효과 두 번 적용 |
| 귀염둥이 | 1·3명 수치 효과 없음. 5명 디버프 관련 유물 두 번, 7명 여기에 아군 소모성 키워드 소모 방지, 9명 모든 유물 두 번 |

분위기는 전투·학교를 넘어 현재 게임에 누적하고 새 게임에서 초기화한다. 분위기 1마다 최종 데미지 +1%p. 100 이상이면 마지막 소녀의 액션 효과 뒤 현재 합동 데미지 +50%p, 300 이상이면 해당 마지막 소녀의 액션을 추가로 한 번 실행한다. 이 시너지의 추가 행동은 턴당 한 번이며 마지막 자리의 소녀가 바뀌어도 갱신되지 않는다. 다른 원인의 재행동을 막지 않는다.

500 이상이면 현재 마지막 소녀가 이미 가진 각 시너지의 인원 계산에 1을 더한다. 5000 이상이면 위 대상 효과를 모든 소녀에게 적용하고, 분위기 추가 행동은 각 소녀당 턴에 한 번이다. 높은 임계값은 낮은 임계값 효과를 함께 유지한다.

사랑꾼의 전투 시작 배치는 Battle 씬에서 배치를 마치고 첫 공격을 시작할 때 확정한다. 이후 이동·재배치로 해당 전투의 저장 보너스는 바뀌지 않는다. 최종 보정은 폴라로이드 → 운동부 → 반항아 → 분위기 → 사랑꾼 → 유물 → 보스 키워드 순서다. 승리 종료 재화는 승리 보상 지급 후 선도부 종료 효과를 적용하며, 패배 종료 효과는 세 번째 턴 결과 때 적용한다. 종료 효과는 전투마다 한 번이다.

귀염둥이 9명은 최고 단계 하나 원칙에 따라 모든 유물 두 번만 적용하고, 7명의 키워드 소모 방지를 별도로 유지하지 않는다.

선도부 획득 배율은 액션 재화·학생 판매·승리 보상·종료 보상 모두에 적용한다. 정수 재화의 소수 부분은 버린다. 최고 단계 하나 규칙에 따라 6명은 별도 획득 배율 없이 종료 시 보유 재화 두 배를 적용한다. 현재 여섯 유물에는 디버프 관련 유물이 없으므로 귀염둥이 5명의 해당 부분은 대상이 없다. 유물의 `DebuffRelated` 분류로 추가할 수 있다.

## 실행과 검증

실제 콘텐츠는 [캐릭터 카탈로그](../../UnityProject/Assets/Scripts/School/PrototypeContent.cs), 순차 행동은 [행동 처리기](../../UnityProject/Assets/Scripts/Combat/BattleActionResolver.cs), 공통 효과는 [시너지 규칙](../../UnityProject/Assets/Scripts/Combat/BattleSynergies.cs)에서 관리한다. 교실의 펫 후보와 전투 카드가 같은 정의를 사용하며, 시작 학생은 아이린이다. 전투 카드는 이름·학년·한글 역할군·부활동·성격·스킬명을 표시하고 실제 효과는 전투 로그로 표시한다.

Unity 6000.3.7f1의 최종 규칙 검사 2,260개와 새 콘텐츠 검사 661개, Windows 빌드를 통과했다. 실제 플레이어에서 12명 표시·강화·전투 진행·학교 복귀 검사 67개, 기존 전투 UI 검사 26개와 펫·유물 검사 33개를 통과했다. 1440×900 운동부와 1280×720 선도부 화면을 확인했다. 수동 마우스 인수 검사와 FMOD 실제 재생은 이번에 수행하지 않았다.

재현: 에디터 `HongikIngan.PrototypeChecks.Run` 또는 배치 빌드 `HongikIngan.Editor.PrototypeBuilder.Build`. 플레이어 인수 `--girl-battle-smoke --smoke-output <폴더>`는 검사용으로 재화·진행을 구성하고 보스 체력을 낮추며, 일반 실행 설정은 바꾸지 않는다. 결과 파일 `girl-battle-result.txt`와 두 PNG를 출력한다. 로컬 로그는 `UnityProject/Logs/GirlsBuildFinal.log`, `GirlBattleSmokeFinal.log`, `GirlBattleRegression.log`, `GirlSchoolRegressionFinal.log`에 있다. 로그·빌드는 커밋하지 않는다.
