# UI 목업 구현 기획서

Claude 아티팩트로 만든 교실·전투 인터랙티브 목업을 Unity 프로젝트 구조에 맞게 옮기기 위한 기획서를 모은 폴더다. 목업은 배치와 연출의 참고이며, 규칙·수치·데이터는 프로젝트 문서와 코드가 우선한다.

## 버전 규칙

- 목업의 연출·배치가 바뀌거나 결정 사항이 확정되면 기존 파일을 고치지 않고 `UI Mockup Implementation v{N}.md`를 새로 만든다. 이전 버전은 이력으로 남긴다.
- 새 버전에는 기준 목업 버전 ID, 이전 버전 대비 변경점, 새로 생긴 프로젝트와의 차이·결정 필요 항목을 적는다.
- 새 버전을 만들면 이 README의 '최신본'과 아래 이력, 그리고 [문서 목차](../README.md)의 링크를 함께 갱신한다.
