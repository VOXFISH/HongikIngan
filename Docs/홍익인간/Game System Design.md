# 게임 시스템 기획서

## 목적과 근거

마법소녀의 배치 순서, 키워드, 공격 트리거와 유물 효과를 조합해 합동 공격의 데미지를 만들고, 최대 3턴 안에 보스를 처치하는 전투 시스템을 정의한다.

근거는 [사용자 제공 플로우차트](Game%20System%20Flowchart.md)와 사용자가 확인한 결과 분기다. 원본에 없는 수치와 처리 규칙은 확정하지 않는다. 문서는 전투 흐름을 다루며, 교실의 구매·영입·보상 규칙까지 새로 정의하지 않는다.

## 주요 용어

| 용어 | 의미 |
| --- | --- |
| 턴 | 인원 재배치부터 합동 공격 및 결과 판정까지의 한 주기 |
| 슬롯 | 마법소녀의 배치 위치이자 왼쪽부터 처리하는 공격 순서의 기준 |
| 키워드 | 아군 또는 보스에 부여되는 효과와 반응 조건의 기준 |
| 액션 트리거 | 조건을 확인하여 공격 액션을 실행하는 계기 |
| 액션 | 키워드 부여, 데미지 증가, 위치 변경 등의 효과 |
| 유물 트리거 | 유물의 효과를 적용하는 계기 |
| 유물 | 해당 트리거에 맞춰 효과를 적용하는 요소. 액션 트리거에도 반응한다. |
| 폴라로이드 | 모든 개별 공격 종료 후, 보유 수에 따라 데미지를 증가시키는 요소. 교실에서 펫 부르기 후 영입하지 않은 마법소녀에 대해 획득한다. |
| 데미지 | 개별 효과와 최종 보정을 반영하여 보스에게 전달하는 값. 화면의 한 구역에 항상 표시하며, 숫자가 변경될 때마다 업데이트한다. 내부 저장·계산은 `float`로 처리하고, 소수점을 버린 정수 형태를 3자리마다 공백으로 구분해 표기한다. 큰 값을 32비트 int로 강제 변환하지 않는다. 10자리 초과 시 `2.05e11`과 같은 과학적 표기법을 이용하며 가수는 소수점 2자리까지 표시한다. |

## 전체 전투 흐름

**턴 시작 → 인원 재배치 → 공격 버튼 입력 → 추가 슬롯·인원 반영 → 배치 처리 → 왼쪽부터 슬롯별 액션 → 최종 데미지 보정 → 필살기 → 보스에게 데미지 전달 → 처치 여부 및 턴 제한 판정**

보스가 살아 있으면 다음 턴에 다시 인원을 재배치할 수 있다. 세 번째 턴의 데미지 적용까지 보스를 처치하지 못하면 게임 오버다.

## 1. 턴 준비와 배치

| 순서 | 처리 | 규칙 |
| --- | --- | --- |
| 1 | 턴 시작 | 이번 턴의 준비 단계로 진입한다. |
| 2 | 인원 재배치 | 플레이어가 드래그하여 마법소녀의 위치를 바꾼다. |
| 3 | 공격 버튼 입력 | 사용자의 입력으로 액션 및 필살기 처리를 시작한다. |
| 4 | 슬롯 추가 버프 반영 | 슬롯 추가 버프에 따른 추가 인원을 적용한다. |
| 5 | 자리 순서대로 배치 | 미리 정해 놓은 자리 순서에 따라 마법소녀를 배치한다. 원본의 '배치 시' 효과를 처리하는 시점이다. |

유물은 각자의 트리거 시점에 맞춰 적용한다. 원본은 유물도 액션 트리거를 함께 사용한다고 명시하므로, 유물을 필살기 마지막에만 적용하는 것으로 제한하지 않는다. 배치 시 효과와 다른 효과가 같은 시점에 발생할 때의 우선순위는 유물(획득순) -> 마법소녀(자리순)으로 처리한다.

## 2. 슬롯별 액션 처리

배치 이후에는 왼쪽 슬롯부터 액션을 처리한다. 각 슬롯에서 액션 트리거의 조건을 확인하고, 자신에게 부여된 키워드 효과를 적용한 뒤 해당 액션을 처리한다. 모든 액션이 끝나지 않았으면 슬롯 처리로 돌아가며, 모두 끝나면 최종 데미지 보정으로 진행한다.

### 반응 조건

| 조건 | 확인할 대상 |
| --- | --- |
| 조건 없음 | 별도의 키워드·이동 조건 없이 반응하는 경우 |
| 자신에게 주어진 키워드에 반응 | 현재 처리 중인 마법소녀에게 부여된 키워드 |
| 아군 전체 키워드에 반응 | 아군 전체의 키워드 상태 |
| 이동에 반응 | 위치 이동 발생 여부 |

각 반응 조건은 event 구독을 이용한 시스템 요소이며, 중복되지 않는다.

### 공격 액션

| 액션 | 결과 |
| --- | --- |
| 아군에게 키워드 부여 | 아군의 키워드 상태를 변경한다. |
| 데미지 합증가 / 데미지 %증가 | 데미지에 합연산 증가 또는 비율 증가 효과를 반영한다. |
| 보스에게 키워드 부여 | 보스의 키워드 상태를 변경한다. 이후 받는 데미지 보정과 연결된다. |
| 상대와 위치 변경 | 대상과 위치를 바꾸며 이동 반응과 연결될 수 있다. 대상은 별도 함수의 전략 패턴으로 선택한다. 전략별 세부 선택 규칙과 이동 후 처리 순서는 미정이다. |

표는 가능한 액션의 종류를 정리한 것이며, 모든 마법소녀가 네 액션을 모두 수행한다는 뜻은 아니다. 액션별 수치, 대상 선택, 한 공격에 포함되는 액션 수는 원본에 없다.

### 아군 액션 시 반응

턴에 관계 없이 '아군 공격 시' 액션 처리로 반응하는 효과를 처리해야 한다. 이때, 아군은 자신을 의미하지 않는다.

## 3. 최종 데미지 보정

모든 슬롯의 공격 처리가 끝난 다음 아래 순서로 진행한다.

1. **폴라로이드 수에 따른 증가:** 보유 수만큼 데미지를 증가시키는 효과를 반영한다.
2. **보스 키워드 적용:** 보스가 받는 데미지를 증가시키는 키워드 효과를 반영한다.

원본에는 개별 공격 액션의 데미지 증가, 폴라로이드 보정, 보스 키워드 보정이 `데미지`에 연결되어 있다. 보스에게 부여한 키워드는 별도로 보스 상태에도 연결된다.
데미지의 연산은 합연산, %p 연산, 곱연산 중 하나이다.

## 4. 합동 공격 연출

| 순서 | 연출 | 게임 규칙과의 관계 |
| --- | --- | --- |
| 1 | 주문 영창 | 가장 많은 시너지부터 '~와 ~와 ~를 담아' 형식의 텍스트로 표현한다. '많다'는 영창 직전 집계 기준이며, 동률 시 지역 -> 직업 시너지 -> 특수 시너지 -> 가나다 순으로 영창한다. |
| 2 | 빔 공격 | 합동 공격의 시각적 연출을 시작한다. |
| 3 | 공격 포지션으로 마법소녀 재배치 | 빔 공격을 위한 포지션으로 이동하는 연출. 추후 구현한다.|
| 4 | 획득한 유물 랜덤 투척 | 원본에 '시스템과는 관계 없는 순수 연출'로 명시되어 있다. 추후 구현하며, 투척의 무작위성이 유물의 실제 효과나 적용 순서를 결정하지 않는다. |
| 5 | 보스에게 데미지 전달 | 계산한 데미지를 보스에게 적용하고 결과 판정으로 진행한다. |

유물의 트리거 효과와 마지막 유물 투척 연출은 구별한다.

## 5. 보스 처치와 3턴 제한

사용자가 확인한 규칙은 **보스 처치 시 교실 복귀, 생존 시 최대 3턴까지 계속**이다.

| 우선순위 | 데미지 적용 후 조건 | 결과 |
| --- | --- | --- |
| 1 | 보스 체력 ≤ 0 | 보스 처치. 교실로 복귀한다. |
| 2 | 보스 체력 > 0, 완료한 턴 수 < 3 | 다음 턴을 시작한다. |
| 3 | 보스 체력 > 0, 완료한 턴 수 = 3 | 게임 오버로 종료한다. |

턴 수는 해당 보스 전투에서 완료한 턴을 기준으로 센다. 세 번째 턴에도 보스 처치 판정을 먼저 하므로, 3턴째에 체력이 0 이하가 되면 승리한다. 교실 복귀 이후의 보상과 다음 스테이지 진입 절차는 이 도표의 범위 밖이다.

## 이전 컨셉과의 차이

이전 신청서 요약(`codex/game-concept-abstract` 브랜치의 `Docs/Game Concept Abstract.md`, 커밋 `064b40e`)은 한 번의 합동 필살기로 목표 데미지 달성 여부를 판정하고, 미달 시 도전을 종료하는 구조였다.

이번 플로우차트와 사용자 확인은 재배치가 가능한 턴, 보스 체력 판정, 최대 3턴의 도전을 구체화한다. 이 기획서는 새로 제공된 전투 흐름을 기준으로 작성했다. 후속 구현에서는 단발 판정 대신 턴 진행과 보스 체력을 관리해야 한다. 기존 컨셉 문서를 통합할 때도 이 차이를 반영해야 한다.

| 합동 공격 연출 | 시너지 집계·동률 정렬, 공격 포지션 이동의 트리거 발생 여부, 데미지 적용의 정확한 연출 시점 |

## 구현 후 확인할 시나리오

다음은 기획 검증 기준이며, 현재 게임 구현이나 실행 테스트를 완료했다는 의미는 아니다.

- 드래그한 배치가 공격 버튼 입력 후 슬롯 처리에 반영된다.
- 추가 슬롯·인원을 반영한 뒤 자리 순서대로 배치하고 왼쪽부터 공격한다.
- 조건에 맞는 키워드·공격 액션·유물 효과가 해당 트리거에서 처리된다.
- 모든 공격이 끝난 뒤 폴라로이드와 보스 키워드 보정을 순서대로 처리한다.
- 동일한 전투 상태에서는 유물 투척 연출의 무작위성이 최종 데미지를 바꾸지 않는다.
- 1·2턴 종료 시 보스가 살아 있으면 다음 턴으로 진행한다.
- 1·2·3턴 중 어느 턴이든 보스 체력이 정확히 0 또는 음수가 되면 교실로 복귀한다.
- 3턴 종료 후 보스 체력이 양수이면 게임 오버가 된다.

## 마법소녀 데이터 확정 규칙

마법소녀는 중복 영입할 수 없으며 1·2·3학년 희귀도를 가진다. 영입·보충 학습·판매(계약 해제) 가격은 학년별로 정한다. Buff·Debuff·Dealer 역할군은 표시 전용이다. 캐릭터 체력·방어력·치명타·속도는 존재하지 않는다.

스킬은 1회 또는 무한 강화 가능으로 나누고, 지정한 강화 변수의 값을 강화 시 교체한다. 액션 대상 선택은 별도 함수에서 전략 패턴으로 처리하며, 키워드 복수 스택 허용은 키워드 정의의 중첩 가능 여부를 따른다. 구체적인 속성과 임시 수치는 [마법소녀 속성 정의](Magical%20Girl%20Attributes.md)를 참조한다. 기존 미정 항목 중 이 절에서 확정한 부분은 이 규칙을 따른다.
